# Historical machine-learning model tuning

Legacy molecular-fingerprint classification experiments, with two layer-specific model-tuning scripts. This repository is separate from my submitted doctoral thesis and the current groundwater research code releases.

## Contents

- `Layer_1.py`: training/test CSV ingestion and classifier tuning for the first experiment layer.
- `Layer_2.py`: the corresponding second-layer workflow.

The scripts contain historical input paths and expect external training/test CSV files. There is no pinned reproduction environment in this snapshot. The presentation update does not change the original code or claim a newly verified result.
